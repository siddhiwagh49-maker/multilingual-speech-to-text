# Multilingual Speech-to-Text

## Overview
Multilingual Speech-to-Text is a Python-based application designed to convert spoken language into written text using speech recognition technology. It aims to make speech transcription easier and more accessible for students and other users.

## Features
- Speech-to-text conversion
- Support for multilingual speech recognition, depending on the configured recognition service
- Python-based implementation
- Designed for capturing and processing spoken input

## Technologies Used
- Python
- Speech Recognition

## Installation and Setup

1. Install Python 3 on your computer.
2. Clone this repository:
   ```bash
   git clone https://github.com/siddhiwagh49-maker/multilingual-speech-to-text.git
   ```
3. Open the project folder:
   ```bash
   cd multilingual-speech-to-text
   ```
4. Install the dependencies after setting up `requirements.txt`.
5. Run the application:
   ```bash
   python main.py
   ```
